FACILITY

瑠璃見サーバー施設

瑠璃見のダム湖周辺に存在する巨大サーバー施設。ネオユビキタスネットワークの基盤であり、町の歪みの象徴。

核心に触れる可能性があります

ダム湖を水冷に利用する国家規模のデータセンター。地下深くにあるIKAROSの演算領域、町中のIoTデバイス、千花のユビキタスコアが重なり、現実と記憶の境界を揺らす中枢になります。

MANUAL

アナログハッチ

瑠璃見サーバー施設の水冷系に残された物理停止手段。デジタル制御外から介入するための手がかり。

核心に触れる可能性があります

荒木の告発記録に示された外側の手段。遠隔制御や改竄された図面を越えて、人の手で過熱した演算系を逃がすために残された出口です。

LINE

同期観測線

瑠璃見サーバー施設の建設時に使われたとされる隠れた接続線。学校や町の古い設備に痕跡が残る。

核心に触れる可能性があります

旧体育館床下の管路などに残る物理的な線。箱庭の記憶と瑠璃見サーバー施設をつなぎ、千花の「ズレた時間」を現実側へ引き寄せる鍵になります。

TECH

サードアイ / スマートアイ

日常生活に浸透した空間コンピュータ。世代ごとに形状や入力方法が変化してきた。

詳しく読む

初期のスタンドアロン型から、スマートフォンの代替、脳波入力、コンタクト型へと発展したデバイス群。作中ではサードアイとも呼ばれ、千花が使用するものは脳波入力を扱う第五世代にあたる。

NETWORK

ネオユビキタスネットワーク

2073年の社会を支える情報基盤。人と街とデバイスを常時接続するネットワーク。

詳しく読む

視界、行動、行政サービス、生活インフラを横断的につなぐ仕組み。便利さの裏側で、現実の見え方や個人の情報管理にも深く関わっています。

INTERFACE

ユビキタスリンカー

脳波とデジタル情報を接続する、極めて特殊なブレインマシンインターフェイス。

核心に触れる可能性があります

量子コンピュータ級の演算能力を、人間が扱える情報量へ翻訳するための装置。最初の被験者は春風千花で、「ズレた時間」やカイの成立にも関わります。

CORE

ユビキタスコア

ユビキタスリンカーとの接続点となるブラックボックス部。個体認証にも関わる。

核心に触れる可能性があります

脳波パターンを用いた暗号化や増幅を担う中核部品。安全装置であると同時に、接続者をめぐる争奪や保護の理由にもなります。
